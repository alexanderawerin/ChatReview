# ChatReview

Главные герои, привычки и моменты Telegram-чата — в слайдах. Одно приложение объединяет разбор статистики, дружескую иронию и более резкую подачу. Фотографии включаются независимо от тона.

## Запуск

Нужен Node.js 22.12+.

```sh
npm ci
npm run dev
```

`npm run build` собирает статическое приложение в `dist/`; `npm run preview` открывает сборку локально. Для размещения достаточно содержимого `dist/`. Относительные пути позволяют размещать приложение в подкаталоге. Открытие `index.html` через `file://` не поддерживается: используйте HTTP-сервер.

## Как пользоваться

1. В Telegram Desktop откройте чат → меню → «Экспорт истории чата».
2. Выберите JSON и нужный период. Для фотографий включите их в экспорт.
3. Нажмите «Загрузить чат», выберите настроение: «Спокойно», «Дружески» или «Пожёстче». По умолчанию выбрано «Спокойно». Загрузите `result.json`; если включили фотографии, выберите всю папку экспорта, сохранив её структуру.
4. Просматривайте слайды на весь экран. Сохраните текущий слайд в PNG или все слайды в ZIP. Для другого настроения вернитесь к загрузке.

Карусель на первом экране показывает три настроения без данных чата. Выбранное превью можно открыть в отдельном окне. Оформление строится на типографике и однотонных палитрах: спокойной нейтральной, дружеской пастельной и контрастной тёмной. Фотографии заполняют весь слайд с обрезкой по центру.

## Приватность и ограничения

- JSON, тексты, имена и изображения обрабатываются в браузере. Нет API, аналитики, внешних шрифтов, CDN-зависимостей, загрузки переписки в ИИ и сохранения чата в localStorage.
- Загрузка самой страницы и ресурсов происходит с хостинга. Ссылка на Telegram Desktop открывает официальный сайт по нажатию.
- Тон меняет подписи, названия номинаций и композицию; числа считаются один раз. Разбор использует правила, а не языковую модель. Номинации описывают активность, а не личность участника.
- Анализируется весь выбранный экспорт. Период задаётся при экспорте в Telegram. Сервисные записи не считаются сообщениями. Участники без сообщений не входят в число пишущих участников.
- Время берётся из дат экспорта; даты с часовым поясом отображаются в локальном времени браузера. Невалидные даты исключаются из временных метрик и идут после датированных сообщений при подсчёте серий.
- Доступный список `recent` у реакций может быть неполным. Отданные реакции и благодарности по реакциям — нижняя оценка, а суммарные полученные реакции берутся из `count`.
- Фотоистории: до пяти фотографий с наибольшим числом реакций, плюс фото со смешными и грустными реакциями. Одна фотография может попасть в разные номинации. Фото без реакций не попадают в подборку. PNG, JPEG, WebP и GIF поддерживаются; анимированные изображения сохраняются одним кадром.
- JSON ограничен 150 МБ, отдельная фотография — 30 МБ. Большие экспорты могут ненадолго задержать интерфейс: анализ выполняется в основном потоке. Если это станет ощутимо, следующий шаг — Web Worker с прогрессом и отменой.
- HTML и ZIP не являются форматами импорта. ZIP экспорта Telegram сначала нужно распаковать. Повреждённая фотография может помешать сохранению: её можно исключить, отключив фотографии.
- PNG сохраняются в 1280 × 720. Экспорт ZIP обрабатывает слайды последовательно; скорость зависит от устройства. Поддержку на физическом iPhone/Safari нужно проверять отдельно.

## Структура

- `src/analyzer.js` — общий расчёт статистики без DOM и сети.
- `src/importer.js` — проверка JSON и сопоставление только выбранных локальных файлов.
- `src/slides.js` — модель слайдов и безопасный HTML для экрана и экспорта.
- `src/main.js` — состояние загрузки, настроек и просмотра.
- `src/export.js` — локальные html2canvas и JSZip, загружаемые при сохранении.
- `design/slide-art-direction.md` — принципы оформления слайдов; `design-qa.md` — журнал проверок, включая предыдущие итерации.

Приложение в корне не зависит от старых папок `ChatRoasted`, `ChatWrapped (base)` и `ChatWrapped (с фото)`. Их можно архивировать или удалить. Они исключены из Git вместе с личными экспортами.

## Проверки

```sh
npm test
npm run lint
npm run format:check
npm run build
```

Тесты проверяют реальные функции анализатора и импортера, шесть сочетаний настроек, разреженные данные, безопасный вывод текста, запрет внешних путей и освобождение локальных URL.

Для проверки браузерного экспорта откройте `/tests/export-browser.html` через dev-сервер и запустите проверку. Она создаёт шесть ZIP на вымышленных данных, открывает каждый архив, декодирует все PNG и проверяет размер 1280 × 720 и пропорции фотографии. Страница теста не входит в production-сборку.
