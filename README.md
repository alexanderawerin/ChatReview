# ChatReview

Веб-приложение для разбора экспорта Telegram-чата и создания слайдов с итогами и шутливыми номинациями.

## Статус

Репозиторий создан для объединения трёх локальных прототипов: Chat Wrapped, Chat Wrapped с фотографиями и ChatRoasted. Объединённое приложение и новый дизайн пока не реализованы. В текущем публичном репозитории находятся только описание проекта и правила исключения локальных файлов.

## Планируемое приложение

- Одна кодовая база в корне репозитория.
- Общая загрузка экспорта и расчёт статистики.
- Независимые настройки фотографий и стиля разбора.
- Обновлённый стартовый экран и слайды результатов.
- Скачивание отдельных слайдов в PNG и полного набора в ZIP.

Анализ планируется выполнять локально в браузере. Состав внешних подключений и ограничения приватности будут описаны вместе с реализацией.

## Локальные исходники и данные

Папки старых вариантов исключены из Git. Новое приложение должно работать независимо от них, чтобы после проверки их можно было архивировать и убрать.

Экспорты Telegram, фотографии, архивы и файлы с секретами не предназначены для публикации. Используйте синтетические данные для примеров и тестов; перед коммитом проверяйте состав изменений.
