# Visual system for chat recaps

The scene supports the social meaning and density of the slide, not a literal metric. There is no dedicated night theme. Quiet moments provide visual pauses between awards.

| Content | Friendly | Roast |
| --- | --- | --- |
| Overview, reactions given/received, gratitude given/received | Celebration, generous central fact | Torn-poster nomination |
| Message volume, streaks, replies, voice notes, caps, questions, self-replies, average length | Plum editorial stage, emoji below fact | Burned comedy poster, punchline before evidence |
| Night/morning activity, conversation endings, returning after silence, short replies | Quiet flat colour | Quiet dark contrast |
| Stickers, links, forwards, edits, emoji usage | Flat colour; meaning carried by emoji and copy | Torn-poster nomination |
| Rankings, words, charts, quotations | Flat colour to preserve reading space | Flat dark stage to preserve reading space |
| Photos | Full-bleed photo with small bottom-centre author | Same photo-first layout |

The hero carousel previews the visual palette (celebration, editorial stage, torn poster, embers), not four fabricated chat results. Slide content remains derived from the imported chat. Generated backgrounds are local assets, not remote dependencies. PNG export preserves 1280×720; photo cropping is central cover.

Generated with the built-in ImageGen tool. Prompt briefs: party = apricot risograph with streamers only at edges; studio = plum paper with coral/lilac edge fragments and quiet central area; poster = torn off-white/black/yellow underground-comedy print; embers = charcoal paper with flames restricted to outer edges. Full prompts are preserved in the task. Calm mode uses none of these images.
